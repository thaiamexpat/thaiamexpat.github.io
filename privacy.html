Privacy Policy

Takeout Rclone ReadOnly · Effective November 2, 2026

Application and intended user

Takeout Rclone ReadOnly is a private, noncommercial OAuth client configured by its owner for use with the open-source Rclone application on a Windows computer. It is for the owner's own Google account, not a service offered to the public.

Google data accessed

When the owner runs an authorized Rclone command, the client may read Google Drive file and folder names, IDs, locations, sizes, related metadata, and file contents needed for local integrity checks. It requests only the Google Drive read-only scope, https://www.googleapis.com/auth/drive.readonly. It does not request Drive write or delete permissions.

How data is used

The owner uses this access to list files, inspect file IDs and locations, download selected files, and compare sizes or cryptographic checksums to validate personally owned backups. The OAuth client itself does not run a hosted service or sell, advertise against, profile, or otherwise monetize Google user data.

Storage and security

Rclone keeps OAuth credentials in its configuration on the owner's computer, not on this website. The owner is responsible for securing that configuration and any locally downloaded Drive files. Files downloaded for verification and any resulting audit records are stored locally until the owner removes them. Separate owner-controlled synchronization tools may place audit reports in the owner's own Google Drive; those operations are not carried out by this read-only OAuth client.

Sharing and third parties

The OAuth client accesses data through Google's APIs and runs in the Rclone desktop program. It does not automatically upload Google Drive content to GitHub Pages, provide it to the public, or transmit it to advertisers. The owner may separately and intentionally share audit records with other services for review, which is outside the operation of this OAuth client.

This informational website is hosted by GitHub Pages. GitHub may process ordinary website access information under its own policies. This website does not add advertising, external analytics scripts, or Google account login features.

Retention and revocation

Local downloads, audit records, and configuration data remain under the owner's control and are retained until manually removed. Authorization may be revoked through Google Account settings under third-party connections. The owner may also remove the Rclone remote and its locally stored credentials.

Questions and changes

Questions about this personal-use OAuth client may be directed to the user-support email listed on its Google OAuth consent screen or through the GitHub repository's issue tracker. This policy will be updated if the workflow's use of Google data materially changes.
