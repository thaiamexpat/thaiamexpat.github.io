Takeout Rclone ReadOnly

A personal, noncommercial Google Drive verification workflow run locally by its owner.

Purpose

This application identifies a private Google OAuth client used by the owner with the open-source desktop program Rclone. The owner uses Rclone from a Windows computer to list Drive files, inspect file identifiers and sizes, and download copies for local integrity checking when explicitly requested.

This website provides information about that OAuth client. It is not an online file-management service, does not accept sign-ins, and does not handle Google authentication tokens.

Access requested

The client requests https://www.googleapis.com/auth/drive.readonly, which permits viewing and downloading files in the Google account that authorizes it. It does not request permission to create, edit, move, or delete files.

Access is limited to the owner's own account and used only under the owner's control.

Privacy and control

Google Drive data is retrieved only in response to commands the owner runs on the local computer. Local downloaded copies and audit records remain under the owner's control.

For details about the data accessed, storage, third-party services, retention, and revoking authorization, see the Privacy Policy.
